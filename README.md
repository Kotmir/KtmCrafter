**KtmCrafter** — это современный мод для Minecraft (загрузчик **Fabric**), который добавляет удобное внутриигровое меню выбора станций и полноценный графический редактор для создания кастомных рецептов прямо на лету.

---

## 🚀 Основные особенности

- 🖥️ **Интерактивное меню (Клавиша G):** Быстрый доступ к выбору ванильных рабочих станций и редактору крафтов.
- 🛠️ **Редактор рецептов:** Удобный графический интерфейс (сетка 3x3 + слот результата), стилизованный под контейнер 9x6.
- 💾 **Сохранение рецептов:** Встроенная система сохранения кастомных рецептов через интерактивный интерфейс.
- ⚡ **Легковесность:** Разработано на базе актуальных версий Fabric API с высокой производительностью.

---

## 📋 Управление и интерфейс

По умолчанию меню мода открывается по нажатию клавиши **`G`**. В открывшемся интерфейсе вы можете выбрать нужную вам станцию или запустить редактор кастомных рецептов.

В самом редакторе:
* **Сетка 3x3** — зона для установки ингредиентов рецепта.
* **Слот результата (справа)** — предмет, который получится в результате крафта.
* **Изумруд** — кнопка подтверждения и сохранения созданного рецепта.
